# BL3 integration references

Read-only historical source snapshots from accepted BL3 0.9.4 r3. These are not
standalone compilable adapters: their full host dependencies remain in B3 DLSS.
They document the control transport, persistence, UEVR menu and Neural seam.
Do not link this folder into the reusable engine or modify the installed game from here.
FoveationPanelTests.lua is a test fixture; its interpreter is not bundled here.
